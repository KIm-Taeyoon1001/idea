# IDEA-001 — ChangeLedger

> **한 줄 설명:** 소규모 기업과 1인 사업자가 경쟁사·공급사·플랫폼의 가격표, 정책, 공지 변경을 놓치지 않도록 추적하고 요약해 주는 변경 감지 SaaS.

## 1. 해결하려는 문제

사업자는 경쟁사의 요금제, 공급사의 가격표, 플랫폼의 이용약관·수수료·정책 페이지를 수시로 확인해야 한다. 하지만 매번 직접 방문해 비교하기 어렵고, 중요한 변경을 늦게 발견하면 비용이나 운영 판단에 영향을 받을 수 있다.

## 2. 핵심 고객

- 여러 SaaS 도구를 사용하는 소규모 기업
- 온라인 쇼핑몰 및 1인 사업자
- 가격·정책 변화를 조사하는 마케터와 운영 담당자
- 외부 공급사 및 파트너 페이지를 관리하는 팀

## 3. 핵심 가치

단순히 페이지가 바뀌었다고 알리는 것이 아니라, **무엇이 언제 어떻게 바뀌었는지**를 이전 버전과 비교해 알려준다.

## 4. MVP 기능

1. 추적할 공개 웹페이지 URL 등록
2. 일정 주기로 페이지 내용 확인
3. 이전 스냅샷과 최신 내용의 차이 감지
4. 변경 문장 하이라이트 및 변경 요약 제공
5. 변경 이력 타임라인 제공
6. 이메일 알림 및 프로젝트별 페이지 그룹화

## 5. 사용자 흐름

1. 사용자가 프로젝트를 생성한다.
2. 추적할 가격표·정책·공지 URL을 등록한다.
3. 서비스가 페이지를 주기적으로 확인한다.
4. 변경이 감지되면 이전 내용과 새 내용을 비교한다.
5. 사용자는 대시보드에서 변경점과 발생 시각을 확인한다.

## 6. 수익 모델 가설

| 플랜 | 가설 기능 |
|---|---|
| Free | 페이지 3개, 확인 주기 제한, 기본 변경 이력 |
| Pro | 페이지 확대, 짧은 확인 주기, 이메일 알림, AI 요약 |
| Team | 팀 공유, 프로젝트 권한, 변경 리포트 내보내기 |

가격은 실제 고객 인터뷰와 사용량 측정 후 검증한다.

## 7. 기술 스택 제안

- Frontend: Next.js + TypeScript
- UI: Tailwind CSS
- Backend: Cloudflare Workers
- Scheduler: Cloudflare Cron Triggers
- Database: Supabase PostgreSQL
- Change detection: HTML 정규화 후 텍스트 diff
- Optional AI: 변경 내용 요약 및 중요도 분류
- Notifications: 이메일 발송 서비스 연동

## 8. 차별화 가설

- 페이지 전체 스크린샷이 아니라 핵심 텍스트 변경을 중심으로 보여준다.
- 가격·수수료·정책 등 업무상 중요한 변경을 우선 표시한다.
- 변경 전후 문장과 확인 시각을 함께 보존해 검증 가능성을 높인다.
- 복잡한 모니터링 설정 없이 URL 등록만으로 시작할 수 있다.

## 9. 검증 계획

1. 소규모 사업자·온라인 판매자 10명에게 현재 페이지 변경을 확인하는 방법을 인터뷰한다.
2. 실제로 놓친 변경 사례와 그로 인한 비용을 조사한다.
3. 수동 등록 URL 5개를 대상으로 변경 감지 프로토타입을 제공한다.
4. 2주간 재방문율과 알림 열람률을 측정한다.
5. 유료 전환 의향을 확인한 뒤 플랜과 가격을 조정한다.

## 10. 주요 리스크 및 대응

- **사이트 구조 변경:** 본문 추출 실패를 감지하고 사용자에게 모니터링 오류를 알린다.
- **동적 페이지:** 초기 MVP는 공개 HTML 페이지 중심으로 제한한다.
- **오탐:** 공백·광고·시간 표시 등 의미 없는 변경을 정규화 단계에서 제외한다.
- **법적·기술적 제한:** 공개 접근 가능한 페이지만 대상으로 하고 robots.txt, 이용약관, 접근 제한 및 요청 빈도를 준수한다. 로그인·유료벽·보안 통제를 우회하지 않는다.
- **AI 요약 오류:** 원문 diff를 항상 함께 제공하고 AI 요약은 보조 정보로 표시한다.

## 11. 성공 지표

- 등록 후 첫 변경 감지까지의 시간
- 주간 활성 프로젝트 수
- 알림 열람률
- 추적 URL 유지율
- 무료 사용자에서 유료 사용자로의 전환율

## 12. 초기 개발 범위

첫 버전은 회원가입, URL 등록, 주기적 확인, 변경 전후 비교, 변경 이력 화면까지 구현한다. AI 요약과 팀 기능은 핵심 변경 감지의 정확도가 확인된 뒤 추가한다.
