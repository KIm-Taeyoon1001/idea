# IDEA-005 — MachHandoff

> **중고 CNC 설비의 제어·소프트웨어 인수인계 검증 플랫폼**  
> 작성일: 2026-11-11 · 상태: 초기 사업 가설 · 고객 인터뷰 및 유료 검증 전

## 1. 한 줄 설명

중고 CNC 설비 거래에서 기계의 외관·가동 상태뿐 아니라 **제어기 설정, 백업 파일, PLC/PMC 자료, 옵션·라이선스, 전기 도면과 기술 문서가 실제로 인계되는지** 표준화된 증빙 패키지로 확인하는 B2B 서비스다.

MachHandoff는 기계의 물리적 상태를 인증하는 검사 서비스가 아니다. 매매 당사자가 디지털 운영 자산을 빠뜨리지 않고 확인·인계하도록 돕는 거래 보조 제품이다.

## 2. 문제와 근본 원인

### 발견한 불편

중고 CNC를 구매할 때 구매자는 스핀들, 축 정밀도, 가동 테스트, 제어기 상태 등을 확인한다. 그러나 거래가 끝난 뒤 다음 자료가 없거나 불완전하다는 사실을 발견할 수 있다.

- CNC 파라미터 및 보정값 백업
- PLC/PMC 프로그램과 관련 설정 자료
- NC 프로그램, 매크로, 공구 데이터 등 계약상 이전 대상 파일
- 제어기 모델·버전·설치 옵션 목록
- 전기 도면, 매뉴얼, I/O 목록 및 장비 구성 문서
- 주요 수리·개조·제어기 교체 이력
- 소프트웨어 라이선스의 소유·사용·이전 가능 여부에 관한 확인 자료
- 백업 파일의 생성 시점, 대상 장비 일치 여부, 복구 테스트 여부

기계가 현재 전원을 켜고 작동한다는 사실만으로 백업이 완전하거나 향후 복구가 가능하다고 단정할 수 없다. CNC 구매 점검 자료에서도 제어기 지원 여부, 문서, 파라미터 백업 및 복구 가능성 확인이 별도 점검 항목으로 다뤄진다.

### 근본 원인 가설

1. **거래 체크리스트의 비표준화:** 매도인·매수인·중개업체가 서로 다른 문서 목록과 확인 기준을 사용한다.
2. **자료의 분산:** USB, 이메일, 개인 PC, 종이 문서에 자료가 흩어져 거래 종료 시 누락 여부를 확인하기 어렵다.
3. **라이선스의 공급사 종속성:** 물리 장비의 소유권 이전과 소프트웨어 사용권 이전은 같은 문제가 아니다. 공급사별 절차와 계약 조건을 확인해야 한다.
4. **증빙 수준의 혼재:** 파일을 받았다는 사실, 파일이 해당 장비의 것이라는 사실, 실제 복구에 쓸 수 있다는 사실은 서로 다르지만 거래 문서에서는 구분되지 않는 경우가 있다.

이 문제가 거래에서 얼마나 자주 발생하는지와 구매자가 별도 비용을 지불할지는 아직 검증되지 않았다.

**차별화 판단:** 관련 검사·유지보수·백업 제품은 이미 존재한다. 따라서 MachHandoff를 단순한 CNC 체크리스트나 백업 관리 제품으로 만들면 차별성이 없다. 검증해야 할 틈새는 **중고 설비 거래 시점에 매도인과 매수인이 함께 사용하는 중립적인 디지털 인계 데이터룸**이다.

공개된 제품 설명만으로 각 경쟁사가 거래 인계 기능을 전혀 제공하지 않는다고 단정하지 않는다. 실제 비교는 데모와 고객 인터뷰로 추가 확인해야 한다.

## 4. 차별화된 해결책

각 자료를 다음 네 상태로 구분해 거래 당사자가 같은 의미로 확인하도록 한다.

- **제출됨(Provided):** 파일이나 문서가 전달됨
- **확인됨(Verified):** 지정된 검토자가 출처·장비 식별 정보·내용을 확인함
- **미검증(Unverified):** 자료는 있으나 일치 여부나 사용 가능성이 확인되지 않음
- **해당 없음(Not applicable):** 해당 장비 또는 거래 조건에 적용되지 않음

핵심은 AI가 모든 문서를 자동으로 '정상' 판정하는 것이 아니다. AI는 식별·분류·누락 탐지를 보조하고, 중요한 항목은 담당자 또는 자격과 권한을 갖춘 기술자가 검토한다.

## 5. 제품 설명

### 매도인 흐름

1. 장비 제조사, 모델, 시리얼, 제어기 제조사·모델·버전을 등록한다.
2. 매뉴얼, 전기 도면, 백업 목록, 옵션 화면, 라이선스 확인서, 정비 이력 등을 업로드한다.
3. OCR이 문서의 식별 정보와 버전을 추출한다.
4. 시스템이 장비 식별 정보 불일치, 필수 문서 누락, 버전 불명확 등의 검토 항목을 표시한다.
5. 매도인이 공개할 자료와 구매자에게만 공유할 자료를 선택한다.

### 매수인 흐름

1. 거래별 보안 링크로 자료 패키지에 접근한다.
2. 항목별 제출·확인·미검증 상태와 근거 문서를 확인한다.
3. 추가 자료를 요청하고 답변 이력을 남긴다.
4. 최종 인계 목록과 당사자 확인 기록을 PDF로 내보낸다.

### 기술자 검토 옵션

협력 CNC 서비스 기술자가 별도 계약으로 다음을 검토할 수 있다.

- 백업 파일의 형식·구성·대상 장비 일치 여부
- 제조사 또는 제어기 공급사에 확인해야 할 라이선스 항목
- 복구 테스트를 실제로 수행했는지와 테스트 범위
- 단종·지원 종료 부품 및 문서의 확인 근거

**복구 테스트를 하지 않았다면 '복구 가능'이라고 표시하지 않는다.** 파일 존재 확인과 실제 복구 테스트를 분리한다.

## 6. 타깃 고객

### 초기 고객

- 중고 CNC 장비 전문 딜러 및 중개업체
- 중고 CNC를 구매하는 소규모·중견 제조업체
- 산업기계 경매·리스·금융사
- CNC 설치·이전·수리·개조 서비스 업체

### 우선 공략 가설

초기에는 거래를 반복하는 중고 CNC 딜러를 우선 공략한다. 딜러는 매물마다 비슷한 자료를 수집하고 구매자 질문에 답해야 하므로, 단일 구매자보다 반복 사용 가능성이 높을 수 있다.

## 7. 고객이 사용해야 할 이유

- **딜러:** 매물별 문서 패키지를 표준화해 구매자 질의와 인계 누락을 줄일 수 있다.
- **구매자:** 거래 전에 무엇을 받았고 무엇이 아직 확인되지 않았는지 구분할 수 있다.
- **서비스 업체:** 고객이 보유한 백업·도면·라이선스 자료의 현황을 정리한 뒤 설치·이전·복구 작업을 시작할 수 있다.
- **금융·경매사:** 거래 문서에 장비의 디지털 인계 항목을 추가할 수 있다.

구매자의 실제 지불 이유가 '안심'에 그치면 반복 매출이 어렵다. 거래 지연 감소, 문서 누락에 따른 재방문·재작업 감소, 분쟁 예방 중 어느 효과가 실제 구매 이유인지 검증해야 한다.

| 딜러 구독 | 월 99,000~299,000원 | 여러 매물 관리, 팀 계정, 거래별 데이터룸, 템플릿 |

가격은 시장 검증 전의 가설이다. 기술자 출장·복구 테스트 비용은 구독료에 포함하지 않고 별도 견적 또는 파트너 비용으로 처리한다.

## 9. MVP 범위

### 반드시 포함

- 장비별 거래 워크스페이스
- 제조사·모델·시리얼·제어기 정보 입력
- 장비 유형별 인계 체크리스트
- PDF·이미지·압축파일 업로드 및 파일 목록
- OCR 기반 문서 분류와 식별 정보 추출
- 제출됨·확인됨·미검증·해당 없음 상태
- 파일 해시 및 업로드 시각 기록
- 구매자용 접근 권한·만료 링크
- PDF 인계 보고서와 당사자 확인 기록

### MVP에서 제외

- CNC 제어기에 직접 연결하는 기능
- 백업 파일의 자동 복구 또는 안전성 보증
- OEM 라이선스의 법적 이전 가능 여부 자동 판정
- 기계의 기계적 정밀도·안전성 인증
- 중고 기계 거래 마켓플레이스
- 모든 제어기 제조사에 대한 자동 데이터 분석

### 권장 초기 기술 구성

- Frontend: Next.js + TypeScript
- Backend/DB: Supabase 또는 PostgreSQL
- Storage: 비공개 객체 스토리지와 만료형 접근 링크
- Document processing: OCR + 문서 분류 모델
- PDF: 서버 측 보고서 생성
- Integrity: SHA-256 해시와 이벤트 로그

## 10. 고객 확보 전략

1. 중고 CNC 딜러 10곳에 매물 인계 자료 수집 과정을 인터뷰한다.
2. CNC 설치·이전·수리 업체에 기술자 검토 파트너십을 제안한다.
3. 딜러에게 첫 1~2건의 거래 패키지를 수작업으로 제작해 주고 실제 누락 항목을 확인한다.
4. 구매자에게 보고서를 제공한 뒤 거래 전 의사결정에 실제 도움이 됐는지 인터뷰한다.
5. 효과가 확인되면 딜러용 매물 등록 템플릿과 반복 구독으로 전환한다.

광고보다 거래 현장에 접근할 수 있는 딜러·서비스 업체 제휴를 우선한다.

## 11. 초기 비용 가설

| 항목 | 초기 운영 가설 |
|---|---:|
| 웹 호스팅·DB·파일 저장 | 월 30,000~100,000원 |
| OCR·LLM 처리 | 보고서당 1,000~10,000원 |
| 도메인·이메일·모니터링 | 월 10,000~40,000원 |
| 기술자 검토 | 건별 별도 정산 |
| 개발 인건비 | 창업자 직접 개발 시 현금 지출에서 제외하되 실제 노동시간으로 기록 |

위 금액은 소량 파일럿을 위한 계획용 추정치이며 공급사 견적이나 검증된 운영비가 아니다. 백업 파일의 보안 저장, 전문 검토, 보험·법률 자문이 필요해지면 비용은 증가한다.

## 12. 확장성

1. 중고 CNC 거래 인계에서 반복 사용성을 검증한다.
2. 제어기·장비별 인계 템플릿과 검토 이력을 축적한다.
3. 딜러·서비스 업체의 반복 거래 워크플로에 연결한다.
4. 수요가 확인되면 산업용 로봇, PLC 제어 설비 등 다른 중고 자동화 설비로 확장한다.
5. 장기적으로 장비의 거래·설치·개조·정비 이력을 소유자 변경과 함께 전달하는 디지털 이력 패키지로 발전시킨다.

초기부터 모든 산업 설비를 지원하지 않는다. CNC 한 분야에서 구매자가 비용을 지불하는지 먼저 확인한다.

## 13. 법적·운영상 리스크

- **소프트웨어 라이선스:** 장비를 구매했다고 소프트웨어 사용권까지 자동으로 이전되는 것은 아니다. 공급사별 약관과 공식 이전 절차를 확인하도록 하고, MachHandoff는 법률 판단을 제공하지 않는다.
- **영업비밀·지식재산:** PLC/PMC 프로그램, NC 프로그램, 매크로, 파라미터에는 영업비밀이나 제3자 권리가 포함될 수 있다. 매도인이 공유 권한을 보유하는지 확인해야 한다.
- **보안:** 백업 파일과 전기 도면은 민감한 운영 자료다. 암호화 저장, 최소 권한, 접근 로그, 링크 만료, 보존 기간 설정, 삭제 요청 절차가 필요하다. 비밀번호·관리자 자격증명은 수집하지 않는다.
- **허위 증빙:** 파일이 제출됐다는 사실만으로 진본성이나 복구 가능성을 보증하지 않는다. 검토 주체와 범위를 기록한다.
- **기술적 책임:** 기계의 안전성·정밀도·법규 적합성 인증으로 오인되지 않도록 모든 보고서에 범위와 한계를 표시한다.
- **데이터 공급:** OEM의 지원 종료·부품 공급 정보는 변경될 수 있으므로 출처와 확인일을 기록하고, 확인되지 않은 항목은 미검증으로 남긴다.

## 14. 30일 시장 검증 계획

### 1주차 — 문제 빈도 확인
- 중고 CNC 딜러 5곳, 구매 제조사 5곳, CNC 서비스 기술자 5명 인터뷰
- 최근 거래 3~5건에서 누락된 자료, 인계 지연, 구매 후 추가 작업을 구체적으로 확인
- '이런 서비스가 있으면 쓰겠다'가 아니라 과거 실제 비용과 대응 사례를 질문

### 2주차 — 수작업 프로토타입
- 딜러가 보유한 실제 매물 3대에 인계 체크리스트 적용
- OCR보다 사람이 확인하는 방식으로 먼저 보고서 제작
- 자료 누락·불일치·미검증 항목이 실제 구매 결정에 영향을 주는지 확인

### 3주차 — 지불 의사 테스트
- 기본 패키지 99,000원과 기술자 검토 패키지 299,000원으로 가격 제안
- 무료 체험 의향이 아니라 실제 결제 또는 유료 파일럿 계약을 측정
- 딜러가 매물마다 반복 사용하려는지 확인

### 4주차 — 계속할지 결정
- 인터뷰 15건 이상
- 실제 매물 패키지 5건 이상
- 유료 파일럿 3건 이상을 1차 목표로 설정
- 유료 수요가 없거나 기존 검사 서비스에 포함되어 추가 지불 의사가 없다면 중단 또는 서비스 업체용 문서 수집 도구로 피벗

## 15. 핵심 검증 지표

- 거래당 인계 자료 누락률
- 매도인이 필수 자료를 제출 완료하는 데 걸리는 시간
- 구매자가 자료 검토를 완료하는 데 걸리는 시간
- 미검증 항목 중 실제 추가 확인이 필요한 비율
- 기본·기술자 검토 패키지의 유료 전환율
- 딜러의 두 번째 거래 재사용률
- 보고서 제작에 들어가는 사람의 검토 시간과 원가

## 17. 현재 판단 및 상태

- **아이디어 상태:** 초기 사업 가설
- **시장 조사:** 공개 웹사이트와 제품 설명을 통한 예비 조사
- **경쟁 강도:** 현장 검사·유지보수·백업 분야의 기존 대안이 존재함. 거래 시점의 중립적 디지털 인계 패키지가 별도 유료 제품으로 성립하는지는 미검증
- **고객 인터뷰:** 미실시
- **유료 파일럿:** 미실시
- **시장 규모·수익성:** 검증 전이므로 추정 TAM이나 매출 전망을 제시하지 않음

**다음 의사결정 기준:** 중고 CNC 딜러와 구매자가 현재 거래에서 실제로 겪는 디지털 자료 인계 문제를 확인하고, 별도 비용을 지불할 만큼 중요한지 검증한다. 기존 현장 검사에 포함되는 기능을 다시 만드는 방향으로 개발하지 않는다.
