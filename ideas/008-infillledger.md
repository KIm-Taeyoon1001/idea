# IDEA-008 — InfillLedger

> **한 줄 설명:** 유럽의 인조잔디 스포츠 시설 운영자가 경기장별 충전재(infill)의 종류·공급사·배치·구매 재고·유지관리 이력을 한곳에 기록하고, 2031년 시장 제한에 대비한 자재 전환 계획을 세우도록 돕는 시설 운영 SaaS.

- **조사 기준일:** 2026-11-14
- **상태:** 초기 사업 가설 — 고객 인터뷰 및 유료 파일럿 전
- **초기 시장 가설:** EU 내 인조잔디 스포츠 시설을 여러 곳 운영하는 지방자치단체, 학교·대학, 스포츠 시설 운영사 및 유지관리 업체
- **제품 범위:** 자재·배치 기록, 재고 흐름, 유지관리 이력, 전환 일정과 증빙 문서 관리
- **중요한 경계:** 법률 해석, 화학 성분 시험, 환경 영향 측정, 경기장 안전성 판단 또는 규제 준수 인증을 대신하지 않는다.

---

## 1. 발견한 불편함

인조잔디 스포츠 시설은 설치 이후에도 충전재 보충, 청소·유지관리, 점검, 외주 작업, 자재 구매와 교체 계획이 반복된다. 한 운영사가 여러 시설을 관리하면 경기장마다 설치 연도, 잔디·충전재 사양, 공급사, 구매 이력, 보유 재고, 유지관리 업체가 달라질 수 있다.

이 정보가 시공 계약서, 공급사 송장, 제품 자료, 유지관리 보고서, 엑셀, 이메일에 흩어져 있으면 다음과 같은 문제가 생길 수 있다는 가설을 세운다.

- 어느 경기장에 어떤 종류의 충전재가 설치되어 있는지 한눈에 파악하기 어렵다.
- 보충 자재의 공급사·구매일·배치 정보와 실제 사용 경기장을 연결하기 어렵다.
- 여러 유지관리 업체가 작업한 이력이 서로 다른 양식으로 남는다.
- 시설별 잔여 재고와 예상 교체 시점을 함께 보지 못해 구매·예산 계획이 늦어질 수 있다.
- 규정 변화에 대비해 어떤 시설부터 자료를 정리해야 하는지 우선순위를 정하기 어렵다.

문제의 핵심은 일반적인 잔디 관리 업무 자체보다, **경기장별 충전재의 출처·배치·재고·작업 이력과 장기 전환 계획이 하나의 기록으로 연결되지 않는 것**이라는 가설이다.

## 2. 근본 원인

1. **시설 단위 데이터 분산:** 시설 관리 시스템은 작업·인력·장비를 중심으로 설계되는 경우가 많고, 충전재의 구매 배치와 잔여 재고를 경기장별로 연결하는 방식은 별도로 정리해야 할 수 있다.
2. **공급사별 문서 차이:** 제품명, 자재 분류, 배치 표기, 송장 형식과 유지관리 보고서가 공급사마다 다르다.
3. **다자간 운영:** 시설 소유자, 잔디 시공사, 유지관리 업체, 시험기관이 서로 다른 기록을 보유한다.
4. **장기 교체 주기:** 시설 교체가 매년 일어나지 않으므로 과거 구매·작업 기록을 담당자 개인의 파일에 의존하기 쉽다.
5. **규정 변화의 시간차:** 구매·설치·유지관리·교체가 수년에 걸쳐 진행되므로 현재 재고와 장기 조달 계획을 함께 볼 필요가 있다.

## 3. 시장 변화와 기존 대안·경쟁 서비스

### 확인한 규제 신호

EU Regulation (EU) 2023/2055는 REACH 부속서 XVII의 합성 고분자 미세입자 제한을 개정했다. EU의 공식 Access2Markets 안내는 인조 스포츠 표면에 사용하는 과립형 충전재에 대한 시장 출시 제한의 적용 시점을 **2031년 10월 17일**로 제시한다. 이는 해당 자재의 시장 출시 제한이지, 기존 경기장을 그 날짜에 일괄 철거해야 한다는 의미로 해석해서는 안 된다.

또한 Regulation (EU) 2021/1199는 특정 과립·멀치의 다환방향족탄화수소(PAH) 제한과 배치 식별 표시를 다룬다. InfillLedger는 관련 문서와 배치 정보를 보관하는 운영 도구일 뿐, 자재의 화학 성분이나 법적 적합성을 판정하지 않는다.

### 경쟁 서비스와 대안

| 서비스·대안 | 확인한 제공 영역 | InfillLedger와의 관계 |
|---|---|---|
| Kiwa Spot On — Artificial Turf | 인조잔디 유지관리 계획, 작업 배정, 디지털 작업 이력, 보증 조건 관련 기록 | 가장 가까운 인접 제품. 유지관리 중심이며, 경기장별 충전재 구매 배치·재고·전환 계획이 핵심인지 별도 검증 필요 |
| FieldTurf Genius | 경기장 사용량과 유지관리 일정·이력 관리, 센서 기반 운영 정보 | 제조사 중심의 경기장 운영·유지관리 제품 |
| TurfHubHQ | 스포츠 잔디 운영, 작업·인력·장비·기록 통합 | 범용 시설 운영 대안 |
| 스프레드시트·공급사 문서·CMMS | 자재 구매, 작업 기록, 점검, 예산 관리 | 현재 고객이 사용할 가능성이 높은 대체 수단 |

**차별화 가설:** 기존 잔디 운영 시스템을 대체하지 않고, 여러 제조사·시공사·유지관리 업체의 기록을 경기장 단위로 연결하는 독립적인 충전재 이력 원장을 제공한다. 핵심은 작업 지시나 센서 모니터링이 아니라 **자재 배치와 재고의 추적성, 시설별 전환 준비 현황**이다.

공개 웹 조사에서 인접 제품은 확인했지만, 이 좁은 업무를 독립적으로 해결하는 제품이 전혀 없다고 단정할 근거는 확보하지 못했다. 경쟁 제품의 실제 기능 범위와 고객의 기존 시스템 사용 여부는 인터뷰 및 데모로 추가 검증해야 한다.

## 4. 차별적 해결책

InfillLedger는 시설 소유자 또는 운영사가 여러 경기장의 충전재 정보를 공급사와 유지관리 업체에 종속되지 않는 형식으로 관리하도록 한다.

1. 경기장마다 설치 연도, 면적, 표면 종류, 충전재 유형, 공급사, 관련 문서를 등록한다.
2. 구매·입고·보충·사용·폐기 기록을 경기장 및 자재 배치와 연결한다.
3. 유지관리 업체가 작업 날짜, 작업 유형, 사용 자재, 관련 송장과 사진을 해당 시설에 추가한다.
4. 시설별 보유 재고와 기록 누락을 보여준다.
5. 운영자가 직접 입력한 시설 수명·예산·구매 조건을 바탕으로 전환 검토 일정을 관리한다.
6. 시설별 이력과 원본 증빙을 묶은 PDF·CSV 보고서를 생성한다.

이 서비스가 제공하는 것은 **기록의 완결성과 계획 가시성**이다. 충전재가 안전한지, 법적으로 허용되는지, 특정 자재로 교체해야 하는지를 자동 판정하지 않는다.

## 5. 제품 설명과 사용자 흐름

### 핵심 모듈

- **Field Registry:** 경기장별 설치 정보, 면적, 표면 유형, 설치사와 보증 문서
- **Infill Register:** 충전재 유형, 제조사·공급사, 제품명, 배치 식별자, 구매일, 수량, 원본 문서
- **Stock Ledger:** 입고·보충·사용·반출·폐기 기록과 잔여 수량
- **Maintenance Log:** 외주 작업자, 작업일, 작업 범위, 투입 자재, 사진과 보고서
- **Transition Planner:** 운영자가 설정한 교체 예상 시점, 구매 가능 재고, 예산 가정, 검토 상태
- **Evidence Export:** 시설별 이력, 배치·송장·작업 보고서와 미확인 항목을 묶은 내보내기

### 기본 사용자 흐름

1. 운영사가 CSV로 여러 경기장을 등록한다.
2. 담당자가 각 경기장의 충전재 사양과 보유 문서를 입력한다.
3. 구매 담당자가 송장과 배치 정보를 추가한다.
4. 유지관리 업체가 공유 링크 또는 제한된 계정으로 작업 기록을 제출한다.
5. 시설 관리자는 누락된 기록과 잔여 재고를 검토한다.
6. 연간 예산 편성 시 경기장별 전환 검토 현황을 내보낸다.

## 6. 타깃 고객과 지불 고객

### 초기 타깃

- EU에서 인조잔디 경기장을 여러 곳 운영하는 지방자치단체
- 학교·대학·스포츠 시설 운영 조직
- 다수 경기장의 유지관리 계약을 맡은 전문 업체
- 여러 고객 시설의 구매·작업 기록을 관리하는 시설 관리 사업자

### 실제 지불 고객 가설

- **1차 구매자:** 여러 경기장의 자산·시설·구매 예산을 책임지는 운영사
- **2차 구매자:** 여러 고객 시설을 관리하고 보고서를 제출하는 유지관리 업체
- **사용자:** 시설 관리자, 구매 담당자, 외주 유지관리 담당자

자재 공급사가 반드시 비용을 지불해야 하는 구조는 아니다. 공급사와 시공사는 기록을 제출하는 무료 협력 사용자로 시작할 수 있다.

## 7. 사람들이 사용해야 할 이유

- 경기장별 자재 이력을 담당자 개인의 파일이 아닌 조직의 기록으로 남긴다.
- 여러 공급사와 유지관리 업체의 자료를 한 형식으로 정리한다.
- 구매 재고와 실제 사용 기록을 연결해 중복 구매 또는 자료 누락을 발견한다.
- 2031년 시장 출시 제한을 앞두고 시설별 준비 상태를 비교한다.
- 기존 CMMS나 시설관리 시스템을 교체하지 않고 보완할 수 있다.

이 가치는 고객이 실제로 여러 경기장을 운영하고, 충전재 기록을 따로 관리하며, 전환 계획을 수립해야 하는 경우에만 크다. 단일 경기장 운영자에게는 스프레드시트가 더 경제적일 수 있다.

위 가격은 시장 가격 조사가 아닌 검증용 가설이다. 실제 지불 의사, 경기장 수별 지불 상한, 예산 담당자는 고객 인터뷰로 확인해야 한다.

## 9. MVP 및 개발 계획

### MVP 범위

1. 조직·사용자·역할 관리
2. 경기장 등록과 CSV 가져오기
3. 충전재 유형·공급사·배치·구매일·수량 기록
4. 입고·보충·사용·반출을 기록하는 간단한 재고 원장
5. 유지관리 작업과 사진·문서 첨부
6. 시설별 이력 PDF·CSV 내보내기
7. 기록 누락과 검토 대기 상태 표시

### MVP에서 제외할 기능

- 화학 성분이나 PAH 시험 결과의 자동 판정
- 법률·규제 적합성 자동 판정
- 센서 및 현장 장비 연동
- 잔디 상태·경기장 안전성 평가
- 자동 자재 추천 또는 교체 지시
- 대형 CMMS·ERP와의 양방향 통합

### 구현 가설

- 프런트엔드: TypeScript 기반 반응형 웹/PWA
- 백엔드·인증·DB: Supabase 또는 동등한 관리형 PostgreSQL
- 파일 저장: S3 호환 객체 스토리지
- 보고서: 서버 측 PDF 생성 및 CSV 내보내기
- 배포: Cloudflare Pages/Workers 또는 유사한 저비용 호스팅

초기에는 별도 센서·하드웨어·AI 모델을 구매하지 않는다. CSV 가져오기와 수동 기록만으로 고객이 실제로 돈을 지불하는지 먼저 검증한다.

## 10. 초기 비용과 운영

### 초기 개발 가설

- 개발 기간: 1인 개발 기준 약 4~6주
- 개발 도구: 무료·오픈소스 도구 중심
- 테스트 운영비: 월 약 US$0~150 수준을 목표로 제한
- 주요 비용: 데이터베이스, 파일 저장, 이메일, 도메인, 백업
- 별도 비용: 규제·표준 전문가 검토, 고객 현장 방문, 법률 검토는 별도

비용은 사용량, 파일 보관량, 이메일 발송량, 호스팅 공급자에 따라 달라진다. 실제 견적이 아닌 초기 예산 가설이다.

### 고객 획득

1. 인조잔디 유지관리 업체와 시설 운영사에 직접 연락해 현재 자재 기록 방식을 조사한다.
2. 시설관리·스포츠시설 관련 협회 및 업계 행사에서 인터뷰를 진행한다.
3. 기존 공급사·시공사와 경쟁하지 않고, 이들의 문서를 고객이 정리하도록 돕는 보완 도구로 제안한다.
4. 3개 시설의 자료를 수동으로 정리하는 파일럿을 제공하고 실제 사용 빈도를 확인한다.
5. 유료 전환이 확인되기 전에는 광고비를 집행하지 않는다.

## 11. 확장성

- 다국가 시설 포트폴리오와 다국어 문서 지원
- 여러 공급사·유지관리 업체의 자료 업로드 표준화
- 경기장 교체·보수 예산 계획
- 자재 공급망 및 배치 이력의 공급사 포털
- 다른 스포츠 표면 자산의 유지관리·자재 이력으로 확장

확장은 초기 고객이 충전재 기록과 전환 계획에 실제 비용을 지불한다는 사실을 확인한 뒤 진행한다.

## 12. 법적·운영상 리스크

| 리스크 | 대응 |
|---|---|
| 규정 해석 오류 | 공식 규정 원문과 전문가 검토를 우선하고, 소프트웨어가 법률 자문이나 적합성 인증을 제공한다고 표현하지 않는다. |
| 기존 경기장 사용과 시장 출시 제한의 혼동 | 2031년 제한을 기존 경기장 일괄 철거 의무로 표시하지 않는다. |
| 배치·구매 기록의 부정확성 | 원본 송장·공급사 문서를 첨부하고 수동 입력과 원본 증빙을 구분한다. |
| 기존 유지관리 제품과 기능 중복 | 범용 작업 관리 대신 자재 배치·재고·전환 기록에 집중한다. |
| 고객 도입 동기 부족 | 규제 일정만으로 구매를 유도하지 말고 실제 재고·예산·문서 정리 비용을 측정한다. |
| 공공기관 영업 주기 | 초기에는 민간 운영사·유지관리 업체의 유료 파일럿으로 검증한다. |
| 문서·계약 정보 유출 | 조직별 접근 통제, 암호화, 백업, 보존기간과 삭제 정책을 설계한다. |
| 자재 분류 오류 | 운영자가 입력한 자재 분류와 공급사 문서의 표현을 별도로 보관하고 자동으로 동등하다고 간주하지 않는다. |

## 13. 30일 시장 검증 계획

### 1주차 — 문제 검증
- EU 내 시설 운영자·유지관리 업체 후보 20곳 조사
- 시설 관리자 8명 이상 인터뷰
- 경기장별 충전재 이력과 재고를 현재 어떤 파일로 관리하는지 확인

### 2주차 — 자료 검증
- 익명화된 경기장 기록 샘플 3건 수집
- 공급사 문서에서 실제로 확보 가능한 필드 확인
- 배치·재고·작업 기록을 하나의 시설 이력으로 연결할 수 있는지 검증

### 3주차 — 수동 파일럿
- 3개 경기장을 대상으로 CSV 기반 데모 운영
- 자재·배치·송장·작업 이력 입력
- 누락된 데이터와 담당자가 자료를 찾는 데 걸리는 시간 측정

### 4주차 — 지불 의사 검증
- 파일럿 고객에게 월 €29~99의 유료 사용 의사 확인
- 최소 2개 조직에서 유료 파일럿 또는 서면 구매 의향 확보를 목표로 한다.
- 무료 사용만 원하거나 기존 시스템으로 충분하다는 응답이 많으면 범위와 고객군을 재검토한다.

### 핵심 지표

- 인터뷰한 시설 운영자 수
- 경기장별 필수 자재 정보 확보율
- 배치·구매·작업 이력의 연결 가능 비율
- 시설 1곳의 초기 자료 정리 소요 시간
- 월간 실제 기록 등록 사용자 수
- 유료 파일럿 전환 조직 수
- 고객이 지불할 의사가 있는 경기장당 월 비용

## 15. 현재 판단

**상태: 초기 사업 가설 — 고객 인터뷰 및 유료 파일럿 전**

규제 변화와 인접한 시설관리 제품은 확인했지만, 충전재 배치·재고·장기 전환 기록을 별도 제품으로 구매하려는 고객이 충분한지는 검증되지 않았다. 특히 Kiwa Spot On 등 기존 제품이 고객의 실제 기록 문제를 이미 해결하고 있을 가능성을 배제할 수 없다.

가장 먼저 검증할 질문은 하나다.

**여러 경기장을 운영하는 조직이 충전재의 구매 배치·잔여 재고·유지관리 이력을 별도 시스템에서 통합 관리하기 위해 매월 비용을 지불할 것인가?**

이 질문에 유료 파일럿으로 답을 얻기 전에는 시장 규모나 수익성을 검증했다고 주장하지 않는다.
